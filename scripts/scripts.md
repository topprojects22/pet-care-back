# 📜 Вспомогательные скрипты

## Обзор

В проекте есть набор полезных shell скриптов для автоматизации различных задач.

---

## 🔧 Скрипты настройки

### `setup.sh` - Первоначальная настройка проекта

Полная настройка проекта с нуля.

```bash
./scripts/setup.sh
```

**Что делает:**
- Создает `.env` файл из `.env.example`
- Генерирует `JWT_SECRET` если не установлен
- Устанавливает зависимости
- Генерирует Prisma клиент
- Применяет миграции (опционально)
- Заполняет базу данных (опционально)

---

### `check-env.sh` - Проверка окружения

Проверяет наличие всех необходимых инструментов и настроек.

```bash
./scripts/check-env.sh
```

**Проверяет:**
- Node.js и npm
- Docker и Docker Compose
- PostgreSQL клиент
- `.env` файл и переменные окружения
- Установленные зависимости
- Prisma клиент

---

## 🗄️ Скрипты базы данных

### `backup-db.sh` - Резервное копирование БД

Создает бэкап базы данных.

```bash
./scripts/backup-db.sh
```

**Что делает:**
- Создает SQL дамп базы данных
- Сжимает бэкап (gzip)
- Сохраняет в `./backups/`
- Удаляет старые бэкапы (старше 7 дней)

**Результат:**
- `backups/petcare_backup_YYYYMMDD_HHMMSS.sql.gz`

---

### `restore-db.sh` - Восстановление БД

Восстанавливает базу данных из бэкапа.

```bash
./scripts/restore-db.sh backups/petcare_backup_20240101_120000.sql.gz
```

**⚠️ ВНИМАНИЕ:** Удаляет все существующие данные!

---

### `migrate-db.sh` - Применение миграций

Применяет миграции базы данных.

```bash
# Development
./scripts/migrate-db.sh development

# Production
./scripts/migrate-db.sh production
```

---

## 🚀 Скрипты деплоя

### `deploy.sh` - Деплой приложения

Деплой приложения через Docker Compose.

```bash
# Development
./scripts/deploy.sh development

# Production
./scripts/deploy.sh production latest
```

**Что делает:**
- Проверяет окружение
- Собирает проект
- Собирает Docker образ
- Останавливает старые контейнеры
- Запускает новые контейнеры
- Проверяет health check

---

### `k8s-deploy.sh` - Деплой в Kubernetes

Деплой приложения в Kubernetes.

```bash
./scripts/k8s-deploy.sh production default
```

**Что делает:**
- Применяет все Kubernetes манифесты
- Ожидает готовности подов
- Показывает статус деплоя

---

## 🔐 Скрипты безопасности

### `generate-ssl.sh` - Генерация SSL сертификатов

Генерирует самоподписанные SSL сертификаты для development.

```bash
./scripts/generate-ssl.sh
```

**Результат:**
- `certs/server.key` - приватный ключ
- `certs/server.crt` - сертификат

**⚠️ ВНИМАНИЕ:** Для production используйте Let's Encrypt или другие сертификаты!

---

### `.env.generate-secret.sh` - Генерация секретов

Генерирует безопасные секреты для `.env` файла.

```bash
./.env.generate-secret.sh
```

## 🧹 Скрипты очистки

### `clean.sh` - Очистка проекта

Удаляет временные файлы, кэш и старые логи.

```bash
./scripts/clean.sh
```

**Что удаляет:**
- `dist/` - скомпилированные файлы
- `node_modules/.cache` - кэш npm
- Старые логи (старше 7 дней)
- `coverage/` - отчеты о покрытии
- Временные файлы

## 📊 Использование seed.ts

### Базовое использование

```bash
npm run seed
```

### С настройкой количества данных

```bash
# Через переменные окружения
SEED_USERS=20 SEED_CLINICS=10 SEED_BOARDINGS=8 npm run seed
```

### Что создает seed:

- **Роли:** admin, user, manager, vet
- **Типы животных:** Cat, Dog, Bird, Rabbit, Hamster
- **Породы:** по 5 пород для каждого типа
- **Клиники:** с услугами и сотрудниками
- **Пользователи:** с настройками и избранными клиниками
- **Питомцы:** с паспортами, картами здоровья, фото
- **Медицинские записи:** вакцинации, медикаменты, визиты
- **Гостиницы:** с бронированиями и отзывами
- **Платежи и отзывы**

### Статистика после seed:

После выполнения seed выводится статистика:
- Количество пользователей
- Количество питомцев
- Количество клиник и услуг
- И другие метрики

## 🔄 Комбинации скриптов

### Полная настройка с нуля

```bash
./scripts/setup.sh
```

### Деплой с бэкапом

```bash
# Создать бэкап
./scripts/backup-db.sh

# Деплой
./scripts/deploy.sh production

# Если что-то пошло не так - восстановить
./scripts/restore-db.sh backups/petcare_backup_*.sql.gz
```

### Обновление production

```bash
# Бэкап
./scripts/backup-db.sh

# Миграции
./scripts/migrate-db.sh production

# Деплой
./scripts/deploy.sh production
```

## 📝 Примечания

1. **Права доступа:** Все скрипты должны быть исполняемыми
   ```bash
   chmod +x scripts/*.sh
   ```

2. **Переменные окружения:** Большинство скриптов требуют `.env` файл

3. **Безопасность:** 
   - Никогда не коммитьте `.env` файл
   - Используйте сильные секреты в production
   - Регулярно создавайте бэкапы

4. **Логи:** Проверяйте логи при ошибках
   ```bash
   docker-compose logs -f
   ```

---

## 🆘 Помощь

Если скрипт не работает:
1. Проверьте права доступа: `chmod +x scripts/script-name.sh`
2. Проверьте наличие необходимых инструментов: `./scripts/check-env.sh`
3. Проверьте `.env` файл
4. Посмотрите логи ошибок
