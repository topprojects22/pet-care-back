## 🚀 Быстрый старт

### 1. Настройка секретов в GitHub:

```
DEPLOY_HOST=your-server-ip
DEPLOY_USER=deploy
DEPLOY_SSH_KEY=<private-ssh-key>
KUBECONFIG=<base64-encoded-kubeconfig>
K8S_NAMESPACE=default (опционально)
```

### 2. Автоматический деплой:

```bash
# Staging (develop ветка)
git push origin develop

# Production (main ветка)
git push origin main
```

### 3. Ручной деплой:

1. GitHub → Actions → CD - Continuous Deployment
2. Run workflow
3. Выберите окружение
4. Запустите

4. **Надежность**
