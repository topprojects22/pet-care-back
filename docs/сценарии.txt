1) Пользователь открывает приложение
    а) Открывается Splash экран
    б) проверяется первый ли раз пользователь открыл приложение (локально сохраненный параметр isFirstVisit)
        если первый раз -> редирект на Onboarding экран -> [переход на пункт в]
        если не первый -> [переход на пункт г]
    в) Открывается Onboarding экран
        пользователь пролистывает 3 экрана с описанием функционала приложения -> [переход на пункт г]
    г) проверяется локально сохраненный параметр userId
            если его нет -> редирект на Auth экран
            если есть -> вызывается сервис getUserInfo (в теле запроса отправляется локально сохраненный параметр userId)
                если ответ 401 или любая другая ошибка -> редирект на Auth экран
                если пришел успешный ответ -> редирект на Home экран
    д) Открывается Home экран
        вызывается сервис getPetType
        (на момент вызова сервиса показываются шиммеры)
            если сервис вернул ошибку -> показываем алерт с ошибкой
        вызывается сервис getUserPetList
            (на момент вызова сервиса показываются шиммеры)
            если сервис вернул ошибку -> показываем алерт с ошибкой
            если пришел успешный пустой ответ -> отображаем кнопку с просьбой добавить питомца (и надпись - "нет ни одного домашнего животного")
                по кнопке добавить питомца открывается модальное окно и с инпутами по животному, тут так же есть dropdown с типом животного и его породой из сервиса getPetType
            если пришел успешный не пустой ответ -> отображаем данные о питомцах на главном экране

    е) В ответе getUserPetList помимо питомцев приходят нотификации к каждому из питомцев и в приложении взводится механизм отображенмя нотификаций в нужное время

2) Пользователь открывает PetList экран
    a) для отображения списка берутся данные из getUserPetList
    б) если список больше 10 -> показывается поле поиска
    в) по клику на эллемент списка -> открывается экран PetPassport
        если данные по паспорту не пришли из сервиса getUserPetList -> открывется часть с инпутами по полям паспорта, в том числе подгрузка картинок -> 
        для сохранения вызывается createPetPassport
        если данные пришли из сервиса getUserPetList -> открывется часть с полями паспорта и кнопкой редактирования

3) Пользователь открывает Notification экран
    а) подтягиваются нотификации с getUserPetList -> отображаются на календаре и списком
        если нотификаций нет, календарь пустой, просьба добавить событие
    б) если пользователь нажимает на событие в календаре или на событие в списке -> открывется модальное окно с детальной информацией по событию
        по нажатию на кнопку удалить -> вызывается deleteNotification 
        по нажатию на кнопку редактировать -> открывется модалка с инпутами по событию
            по нажатию на кнопку обновить -> вызывается updateNotification 
    в) если пользователь нажимает на пустой день в календаре или на кнопку добавить событие -> открывется модалка с инпутами по событию
        по нажатию на кнопку сохранить -> вызывается createNotification 

4) Пользователь открывает Profile экран
    а) отображаются данные из getUserInfo (имя, картинка)
    б) есть кнопка выйти - затирает токены на устройстве, редирект на Auth экран
    в) есть кнопка загрузить аватар - вызывает сервис uploadUserImage
        если сервис вернул ошибку -> показываем алерт с ошибкой
        если успешный ответ обновляем аватар
