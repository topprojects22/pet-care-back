# 🔧 Настройка переменных окружения

## ⚠️ Важно

Приложение требует настройки переменных окружения перед запуском.

## 🚀 Быстрая настройка

### 1. Скопируйте пример файла

```bash
cp .env.example .env
```

### 2. Сгенерируйте JWT_SECRET

**JWT_SECRET должен быть минимум 32 символа!**

```bash
# Вариант 1: Использовать скрипт
./.env.generate-secret.sh

# Вариант 2: Вручную
openssl rand -base64 32
```

### 3. Обновите .env файл

Откройте `.env` и замените:
```
JWT_SECRET=your-generated-secret-here-minimum-32-characters
```

### 4. Настройте DATABASE_URL

Укажите правильный URL для вашей базы данных:
```
DATABASE_URL=postgresql://user:password@localhost:5432/petcare?schema=public
```

## 📋 Обязательные переменные

- `DATABASE_URL` - URL подключения к PostgreSQL
- `JWT_SECRET` - Секретный ключ для JWT (минимум 32 символа)

## 🔒 Безопасность

### Development
- Можно использовать простой секрет для разработки
- Минимум 32 символа

### Production
- **ОБЯЗАТЕЛЬНО** используйте длинный случайный секрет
- Генерируйте через: `openssl rand -base64 32`
- Никогда не коммитьте `.env` в git
- Используйте секреты в CI/CD системах

## 🛠️ Генерация секретов

### JWT_SECRET
```bash
openssl rand -base64 32
```

### Другие секреты
```bash
# Для паролей
openssl rand -base64 24

# Для токенов
openssl rand -hex 32
```

## ✅ Проверка

После настройки проверьте:

```bash
# Проверка валидации
npm run build

# Запуск приложения
npm run start:dev
```

Если видите ошибку валидации, проверьте:
1. Все обязательные переменные установлены
2. JWT_SECRET минимум 32 символа
3. DATABASE_URL корректный
