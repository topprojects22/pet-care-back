## 1. Pet Profile

### 1.1. Цель и Контекст

**Бизнес-задача:** Детальный просмотр информации о питомце: фото, описание, местоположение, активности и быстрый доступ к ветеринарному паспорту. Центральный экран для работы с конкретным питомцем.

**Место в сценарии:** Отображается при выборе питомца из списка (Pet List) или из других мест приложения. Является промежуточным экраном между списком и детальной информацией (паспорт).

**Ключевые функции:** Просмотр фото, описание, местоположение, список активностей, переход к паспорту.

### 1.2. Элементы Интерфейса и Функциональность

#### 1.2.1. Структура Экрана

**Компонент: TitleTopWidget (Header)**
- Заголовок: "Lunas profile" (динамически из данных питомца)
- Левая иконка: Стрелка назад (`left-arrow-20`)
  - Действие: `viewModel.navigateBack()`
- Правая иконка: Редактирование (`edit-20`)
  - Действие: Переход на редактирование (опционально)
- Отступы: Горизонтальные 20 points

**Компонент: ImageCarouselUI (Карусель фото)**
- Тип: Горизонтальная прокручиваемая карусель
- Изображения: `assetImages: ["image_1"]` (динамически из `pet.photos`)
- Автоплей: `isAutoPlay: true`
- Высота: 250 points
- Закругление: 16 points
- Позиция: Верх ScrollView

**Секция "About me":**
- Заголовок: "About me" (локализованный)
- Описание: Длинный текст о питомце (из `pet.description` или заглушка)
- Стиль: Заголовок bold, описание серый цвет, multiline
- Отступы: Горизонтальные 20 points

**Компонент: FlowLayout (Теги)**
- Тип: Адаптивная сетка тегов
- Теги: Примеры ("fe", "female 1", "femal", "fem")
- Компонент: `TagUI`
- Отступы: Горизонтальные 10 points, вертикальные 6 points
- Выравнивание: По левому краю

**Секция "Локация":**
- Заголовок: "Локация" (локализованный)
- Иконка: `location-20`
- Текст: "Текущее местоположение"
- Адрес: "Москва, ул. Примерная, д. 1" (заглушка)
- Фон: `.systemBackground`
- Закругление: 16 points
- Отступы: Горизонтальные 20 points, внутренние padding

**Секция "Активности":**
- Заголовок: `TitleListWidget` с текстом "Активности"
- Список: Первые 5 активностей из `pet.notificationList`
- Компонент: `NotificationCardUI`
- Структура карточки:
  - Заголовок: `notification.name`
  - Описание: `notification.description`
  - Дата: Форматированная дата и время
  - Иконка: `bell-20`
- Пустое состояние: Если активностей нет
  - Иконка: `calendar.badge.exclamationmark`
  - Текст: "Нет активностей"
  - Подтекст: "Активности питомца появятся здесь"

**Кнопка "Паспорт питомца":**
- Стиль: Primary button, размер large, цвет indigo
- Текст: "Паспорт питомца" (локализованный)
- Действие: `viewModel.navigateToPetPassport(petId: petId)`
- Отступы: Горизонтальные 20 points, нижний 20 points

#### 1.2.2. Интерактивность

**Swipe по карусели фото:**
- Горизонтальный swipe → переход между фото
- Автоплей: Автоматическая прокрутка (если включена)

**Тап на стрелку назад:**

**Тап на иконку редактирования:**
- Переход на экран редактирования (если реализовано)

**Тап на активность:**

**Тап на кнопку "Паспорт питомца":**

**Валидация не требуется:**

### 1.3. Техническая Реализация

#### 1.3.1. Сервисы и API

**API Endpoint: GET /pet/{petId}**
- Метод: `GET`
- Путь: `/pet/{petId}`
- Требует авторизации: Да (`requiresAuth: true`)
- Кэш: `cacheIfValid(300)` (5 минут)
- Retry: `exponential(maxAttempts: 3, initialDelay: 1.0)`

**Ответ при успехе (200 OK):**
```json
{
  "data": {
    "id": 1,
    "name": "Луна",
    "type": "dog",
    "breed": "Бигль",
    "avatarPath": "url_to_avatar",
    "photos": [
      {"id": "1", "url": "url_to_photo", "isPrimary": true}
    ],
    "notificationList": [
      {
        "id": 1,
        "name": "Прививка",
        "description": "Ежегодная вакцинация",
        "date": "2025-01-15",
        "startTime": "10:00"
      }
    ]
  }
}
```

**Use Case: FetchPetProfileUseCase**
- Входные данные: `petId: Int`
- Выходные данные: `NetworkResult<Pet>`
- Действия:
  1. Вызов `PetNetworkService.fetchPetProfile(petId:)`
  2. Конвертация DTO в Entity
  3. Обновление `currentPet` в ViewModel

**Загрузка фото (опционально):**
- Endpoint: `POST /pets/{petId}/photos/upload`
- Use Case: `UploadPetPhotoUseCase`
- Действие: Загрузка фото после создания/редактирования

#### 1.3.2. Состояния Экрана

**Состояние: Загрузка**
- Индикатор загрузки (если реализовано)
- Placeholder для фото и данных
- Кнопки неактивны

**Состояние: Успех**
- Все данные загружены
- Фото отображаются в карусели
- Описание и активности отображаются
- Кнопки активны

**Состояние: Ошибка**
- Alert с сообщением об ошибке
- Если `unauthorizedError` → автоматический logout
- Возможность повторить загрузку

**Состояние: Пустое (активности)**
- Если `notificationList` пуст → отображается пустое состояние
- Предложение добавить активности

#### 1.3.3. Навигация

**Исходящие переходы:**
- Ветеринарный паспорт → `.petPassport(petId:)`
- Редактирование → `.editPetPassport(petId:)` (если реализовано)
- Календарь → `.calendar` (при тапе на активность)

**Входящие переходы:**
- Из Pet List (тап на карточку)
- Из других мест приложения (deep links)

**Методы навигации:**
- `coordinator.showPetPassport(for: petId)` - переход на паспорт
- `coordinator.goBack()` - возврат назад

#### 1.3.4. Данные

**Модель Pet:**
```swift
struct Pet: Identifiable, Codable {
    let id: Int
    let name: String
    let type: PetType
    let breed: String?
    let pasport: PetPassport?
    let photo: String?
    let photos: [PetPhoto]?
    let notificationList: [PetNotification]?
}
```

**Модель PetNotification:**
```swift
struct PetNotification: Identifiable, Codable {
    let id: Int
    let name: String
    let description: String?
    let date: String
    let startTime: String?
    let isCompleted: Bool?
}
```

**Состояние ViewModel:**
- `currentPet: Pet?` - текущий питомец
- `petPhoto: CommonSuccess?` - результат загрузки фото

#### 1.3.5. Обработка Ошибок

**Типы ошибок:**
- **Неавторизован (401):** Автоматический logout
- **Не найдено (404):** Сообщение "Питомец не найден"
- **Сервер (500):** Общая ошибка сервера
- **Сеть:** Ошибка подключения

**Стратегия обработки:**
- Ошибки логируются с контекстом `["action": "load_pet_profile", "pet_id": petId]`
- Пользователь может повторить загрузку

#### 1.3.6. Аналитика

**Отслеживаемые события:**
- `screen_view: PetProfile` - при появлении экрана
- `pet_profile_loaded` - при успешной загрузке (параметры: `pet_id`)
- `navigate_to_pet_passport` - переход на паспорт (параметры: `pet_id`)
- `pet_photo_uploaded` - при загрузке фото (параметры: `pet_id`)

## 2. Pet Passport

### 2.1. Цель и Контекст

**Бизнес-задача:** Ветеринарный паспорт питомца с полной медицинской информацией: вакцинации, посещения ветеринара, основные данные. Возможность экспорта в PDF и генерации QR-кода для быстрого доступа ветеринара к информации.

**Место в сценарии:** Отображается из Pet Profile (кнопка "Паспорт питомца") или напрямую из навигации. Является детальным экраном с медицинской информацией.

**Ключевые функции:** Просмотр данных, вакцинации, история посещений, экспорт в PDF, QR-код.

#### 2.2.1. Структура Экрана

**Компонент: TitleTopWidget (Header)**

- Левая иконка: Стрелка назад (`left-arrow-20`)
  - Действие: `viewModel.navigateBack()`
- Правая иконка: Редактирование (`edit-20`)
  - Действие: Открытие модального окна редактирования
- Отступы: Горизонтальные 20 points

**Секция "Основная информация" (basicInfoSection):**

    - Значение: `pet.name` (callout, серый)
  - **Возраст:**

    - Значение: `pet.age` (лет)
  - **День рождения:**

    - Подзаголовок: "Добавьте информацию о прививках"
  - **Список вакцинаций:**
    - Тип: Горизонтальный ScrollView
    - Компонент: `VaccinationCard`

  - Действие: Переход к полному списку (если реализовано)

    - Диагноз: `DetailRow` с иконкой `stethoscope`
    - Назначения: `DetailRow` с иконкой `pills`
- Интерактивность: Тап на header → раскрытие/сворачивание деталей
- Анимация: Плавное раскрытие с spring анимацией
- Фон: `.systemBackground`
- Закругление: 12 points
- Тень: Легкая тень

**Кнопка "Экспорт в PDF":**
- Стиль: Primary button, размер regular
- Текст: "Экспорт в PDF"
- Действие: `viewModel.generatePDF()`
- Состояние: Неактивна во время загрузки (`isLoading`)
- Отступы: Горизонтальные 20 points

**Модальное окно редактирования:**

- Данные: `petId` и `passport`
- Действие: Редактирование данных паспорта

**Типы ошибок:**
- **Неавторизован (401):** Автоматический logout
- **Не найдено (404):** Сообщение "Паспорт не найден"
- **Сервер (500):** Общая ошибка сервера
- **Сеть:** Ошибка подключения

**Стратегия обработки:**
- Ошибки логируются с контекстом `["action": "load_pet_passport", "pet_id": petId]`
- При ошибке генерации PDF → сообщение пользователю

#### 2.3.6. Аналитика

**Отслеживаемые события:**
- `screen_view: PetPassport` - при появлении экрана
- `pet_passport_loaded` - при успешной загрузке (параметры: `pet_id`)
- `pet_passport_pdf_generated` - при генерации PDF (параметры: `pet_id`)
- `pet_passport_qr_fetched` - при получении QR (параметры: `pet_id`)
