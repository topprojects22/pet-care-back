## 1. Shelter List (Каталог приютов)

### 1.1. Цель и Контекст

**Бизнес-задача:** Предоставление каталога проверенных приютов для животных с возможностью поиска, фильтрации и просмотра информации. Упрощение процесса поиска приютов и питомцев, готовых к усыновлению.

**Место в сценарии:** Доступен через навигацию из Home или отдельный раздел "Благотворительность". Является отправной точкой для поиска приютов, усыновления питомцев и пожертвований.

**Ключевые функции:** Поиск приютов, фильтрация, просмотр списка, переход к детальной информации.

### 1.2. Элементы Интерфейса и Функциональность

#### 1.2.1. Структура Экрана

**Компонент: Navigation Header**
- Заголовок: "Приюты для животных" (локализованный)
- Кнопка поиска: В правом углу
- Иконка: `search-20`
- Действие: Открытие поиска

**Компонент: Search Bar**
- Поле поиска: "Поиск приютов..."
- Иконка: `search-20`
- Действие: Фильтрация списка в реальном времени
- Поиск по: Названию, адресу, описанию

**Компонент: Filter Bar**
- Фильтры:
  - **Все** (по умолчанию)
  - **С питомцами для усыновления**
  - **Принимают пожертвования**
  - **Проверенные** (верифицированные)
- Интерактивность: Тап на фильтр → обновление списка

**Компонент: Shelter List**
- Тип: Вертикальный список карточек приютов
- Прокрутка: Вертикальный ScrollView
- Pull-to-Refresh: Обновление списка
- Infinite Scroll: Автоматическая подгрузка

**Структура карточки приюта:**
- **Изображение:** Фото приюта или логотип
- **Название:** Название приюта
- **Адрес:** Город, адрес
- **Статус:** Верифицирован (бейдж, если проверен)
- **Статистика:**
  - Количество питомцев для усыновления
  - Рейтинг (если есть отзывы)
- **Краткое описание:** 1-2 строки
- **Действие:** Тап → переход на детальную информацию

#### 1.2.2. Интерактивность

**Тап на карточку приюта:**
- Переход на детальную информацию о приюте
- Действие: `viewModel.showShelterDetail(shelterId:)`
- Аналитика: `shelter_detail_opened` с параметром `shelter_id`

**Поиск:**
- Ввод текста → фильтрация в реальном времени
- Поиск по названию, адресу, описанию
- Очистка поиска → возврат к полному списку

**Тап на фильтр:**
- Обновление списка приютов
- Подсветка активного фильтра
- Аналитика: `shelter_filter_applied`

**Pull-to-Refresh:**
- Потягивание вниз → обновление списка
- Вызов `viewModel.loadShelters()`

#### 1.2.3. Валидация

**Валидация не требуется:**
- Экран информационный, пользовательский ввод только в поиске

### 1.3. Техническая Реализация

#### 1.3.1. Сервисы и API

**API Endpoint: GET /charity/shelters**
- Метод: `GET`
- Путь: `/charity/shelters`
- Требует авторизации: Нет (публичный доступ)
- Query параметры:
  - `page`: Номер страницы
  - `limit`: Количество на странице (по умолчанию 20)
  - `search`: Текст поиска (опционально)
  - `hasPets`: Есть питомцы для усыновления (опционально)
  - `acceptsDonations`: Принимает пожертвования (опционально)
  - `verified`: Только проверенные (опционально)
  - `city`: Город (опционально)
- Кэш: `cacheIfValid(600)` (10 минут)
- Retry: `exponential(maxAttempts: 3, initialDelay: 1.0)`

**Ответ при успехе (200 OK):**
```json
{
  "data": [
    {
      "id": "shelter_123",
      "name": "Приют для бездомных животных",
      "description": "Небольшой приют, помогающий бездомным животным",
      "address": {
        "city": "Москва",
        "street": "ул. Примерная, д. 1",
        "coordinates": {
          "lat": 55.7558,
          "lng": 37.6173
        }
      },
      "phone": "+79001234567",
      "email": "shelter@example.com",
      "website": "https://shelter.example.com",
      "image": "url_to_image",
      "logo": "url_to_logo",
      "isVerified": true,
      "stats": {
        "petsAvailable": 15,
        "petsAdopted": 200,
        "rating": 4.8,
        "reviewCount": 50
      },
      "acceptsDonations": true,
      "donationInfo": {
        "methods": ["card", "bank_transfer"],
        "minAmount": 100
      }
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "hasMore": true
  }
}
```

**Use Case: FetchSheltersUseCase**
- Входные данные: `ShelterListRequest(filters, pagination)`
- Выходные данные: `NetworkResult<[Shelter]>`
- Действия:
  1. Создание `NetworkRequest` с query параметрами
  2. Вызов `CharityNetworkService.fetchShelters()`
  3. Конвертация DTO в Entities
  4. Возврат массива `Shelter`

#### 1.3.2. Состояния Экрана

**Состояние: Загрузка**
- Индикатор загрузки
- Placeholder для списка

**Состояние: Успех**
- Список приютов отображается
- Карточки заполнены данными
- Применены фильтры (если выбраны)

**Состояние: Пустое**
- Если нет приютов → отображается пустое состояние
- Иконка и текст "Приюты не найдены"
- Предложение изменить параметры поиска/фильтры

**Состояние: Ошибка**
- Alert с сообщением об ошибке
- Возможность повторить загрузку

**Состояние: Загрузка следующей страницы**
- Индикатор внизу списка
- Автоматическая подгрузка при прокрутке

#### 1.3.3. Навигация

**Входящие переходы:**
- Из Home (навигация)
- Из других мест приложения

**Исходящие переходы:**
- Детальная информация → `.shelterDetail(shelterId:)`
- Усыновление → `.petAdoption(petId:)`
- Пожертвование → `.donation(shelterId:)`

**Методы навигации:**
- Открытие: `coordinator.showShelterList()`
- Детальная информация: `coordinator.showShelterDetail(id:)`

#### 1.3.4. Данные

**Shelter:**
```swift
struct Shelter: Identifiable, Codable {
    let id: String
    let name: String
    let description: String
    let address: ShelterAddress
    let phone: String?
    let email: String?
    let website: String?
    let image: String?
    let logo: String?
    let isVerified: Bool
    let stats: ShelterStats
    let acceptsDonations: Bool
    let donationInfo: DonationInfo?
}

struct ShelterAddress: Codable {
    let city: String
    let street: String
    let coordinates: Coordinates?
}

struct ShelterStats: Codable {
    let petsAvailable: Int
    let petsAdopted: Int
    let rating: Double?
    let reviewCount: Int
}

struct DonationInfo: Codable {
    let methods: [String]
    let minAmount: Decimal
}
```

#### 1.3.5. Обработка Ошибок

**Типы ошибок:**
- **NetworkError:** Ошибка сети
- **ServerError:** Ошибка сервера

**Отображение ошибок:**
- Alert с понятным сообщением
- Возможность повторить загрузку
- Логирование через `Logger`

#### 1.3.6. Аналитика

**Отслеживаемые события:**
- `screen_view: ShelterList` - при появлении экрана
- `shelter_searched` - поиск приютов (параметры: `search_query`)
- `shelter_filter_applied` - применение фильтра (параметры: `filter_type`, `filter_value`)
- `shelter_detail_opened` - открытие детальной информации (параметры: `shelter_id`)

## 2. Shelter Detail (Детальная информация о приюте)

### 2.1. Цель и Контекст

**Бизнес-задача:** Детальная информация о приюте с фотографиями, описанием, контактами, списком питомцев для усыновления и возможностью пожертвования. Полный контекст для принятия решения об усыновлении или пожертвовании.

**Место в сценарии:** Открывается при тапе на карточку приюта из списка. Пользователь может просмотреть детальную информацию, список питомцев, оставить заявку на усыновление или сделать пожертвование.

### 2.2. Элементы Интерфейса и Функциональность

#### 2.2.1. Структура Экрана

**Компонент: Header Image**
- Изображение приюта (большое, вверху)
- Кнопка "Назад": В левом углу
- Кнопка "Поделиться": В правом углу (опционально)

**Компонент: Shelter Info Card**
- Название приюта
- Статус верификации (бейдж)
- Адрес с кнопкой "Показать на карте"
- Контакты:
  - Телефон (кликабельный)
  - Email (кликабельный)
  - Сайт (кликабельный)
- Рейтинг и отзывы (если есть)

**Компонент: Description**
- Полное описание приюта
- История, миссия, деятельность
- Многострочный текст с прокруткой

**Компонент: Statistics**
- Карточка со статистикой:
  - Питомцев для усыновления: N
  - Усыновлено: N
  - Рейтинг: X.X (N отзывов)

**Компонент: Available Pets**
- Заголовок: "Питомцы для усыновления"
- Горизонтальная карусель или сетка
- Карточки питомцев:
  - Фото
  - Имя
  - Возраст
  - Порода (если известна)
- Кнопка "Смотреть всех" → переход на полный список

**Компонент: Action Buttons**
- Кнопка "Сделать пожертвование" (Primary button)
- Кнопка "Оставить заявку на усыновление" (Secondary button)
- Кнопка "Связаться с приютом" (Text button)

#### 2.2.2. Интерактивность

**Тап на питомца:**
- Переход на детальную информацию о питомце
- Действие: `viewModel.showPetDetail(petId:)`

**Тап на "Сделать пожертвование":**
- Переход на экран пожертвования
- Действие: `viewModel.showDonation(shelterId:)`

**Тап на "Оставить заявку на усыновление":**
- Переход на экран усыновления
- Действие: `viewModel.showAdoption(shelterId:)`

**Тап на "Показать на карте":**
- Открытие карты с местоположением приюта
- Или переход в приложение карт

**Тап на телефон/email:**
- Открытие системного диалога звонка/письма

**Тап на "Поделиться":**
- Системный share sheet
- Копирование ссылки на приют

### 2.3. Техническая Реализация

#### 2.3.1. Сервисы и API

**API Endpoint: GET /charity/shelters/{shelterId}**
- Метод: `GET`
- Путь: `/charity/shelters/{shelterId}`
- Требует авторизации: Нет

**API Endpoint: GET /charity/shelters/{shelterId}/pets**
- Метод: `GET`
- Путь: `/charity/shelters/{shelterId}/pets`
- Query параметры: `page`, `limit`, `status` (available|adopted)

**Use Case: FetchShelterDetailUseCase**
- Входные данные: `ShelterId`
- Выходные данные: `NetworkResult<Shelter>`

**Use Case: FetchShelterPetsUseCase**
- Входные данные: `ShelterId, page, limit`
- Выходные данные: `NetworkResult<[AdoptionPet]>`

## 3. Pet Adoption (Усыновление питомца)

### 3.1. Цель и Контекст

**Бизнес-задача:** Упрощение процесса усыновления питомца из приюта через онлайн-анкету и запись на знакомство. Снижение барьеров для усыновления и помощь приютам в поиске ответственных владельцев.

**Место в сценарии:** Открывается из детальной информации о приюте или из списка питомцев. Пользователь заполняет анкету, выбирает питомца и оставляет заявку на знакомство.

### 3.2. Элементы Интерфейса и Функциональность

#### 3.2.1. Структура Экрана

**Компонент: Pet Info Card**
- Фото питомца
- Имя, возраст, порода
- Описание характера и истории
- Особые потребности (если есть)

**Компонент: Adoption Form**
- Поля анкеты:
  - **ФИО:** Текстовое поле
  - **Email:** Email поле
  - **Телефон:** Телефонное поле
  - **Адрес:** Текстовое поле
  - **Опыт содержания животных:** Многострочное поле
  - **Жилье:** Выбор (квартира/дом/другое)
  - **Есть ли другие животные:** Переключатель
  - **Готовность взять ответственность:** Переключатель
  - **Дополнительная информация:** Многострочное поле
- Валидация: Все обязательные поля должны быть заполнены

**Компонент: Visit Booking**
- Календарь для выбора даты знакомства
- Выбор времени (слоты от приюта)
- Примечание: "Выберите удобное время для знакомства с питомцем"

**Компонент: Submit Button**
- Кнопка "Отправить заявку" (Primary button)
- Состояния: Активна/Неактивна/Загрузка
- Действие: `viewModel.submitAdoptionRequest()`

#### 3.2.2. Интерактивность

**Заполнение анкеты:**
- Валидация в реальном времени
- Ошибки отображаются под полями
- Автосохранение черновика (опционально)

**Выбор даты и времени:**
- Тап на дату в календаре
- Выбор доступного слота времени
- Валидация: Дата должна быть в будущем

**Отправка заявки:**
- Валидация всех полей
- Отправка на сервер
- Подтверждение отправки
- Переход на экран успеха

### 3.3. Техническая Реализация

#### 3.3.1. Сервисы и API

**API Endpoint: POST /charity/adoption/request**
- Метод: `POST`
- Путь: `/charity/adoption/request`
- Требует авторизации: Да
- Тело запроса:
```json
{
  "petId": "pet_123",
  "shelterId": "shelter_456",
  "applicant": {
    "fullName": "Иван Иванов",
    "email": "ivan@example.com",
    "phone": "+79001234567",
    "address": "Москва, ул. Примерная, д. 1"
  },
  "questionnaire": {
    "experience": "Имею опыт содержания собак",
    "housing": "apartment",
    "hasOtherPets": false,
    "readyForResponsibility": true,
    "additionalInfo": "Дополнительная информация"
  },
  "visitDate": "2025-01-20T14:00:00Z"
}
```

**Ответ при успехе (201 Created):**
```json
{
  "requestId": "req_789",
  "status": "pending",
  "message": "Заявка успешно отправлена. Приют свяжется с вами в ближайшее время."
}
```

**Use Case: SubmitAdoptionRequestUseCase**
- Входные данные: `AdoptionRequestInput(petId, shelterId, applicant, questionnaire, visitDate)`
- Выходные данные: `NetworkResult<AdoptionRequest>`

## 4. Boarding Search (Поиск передержек)

### 4.1. Цель и Контекст

**Бизнес-задача:** Поиск проверенных передержек для питомцев на время отпуска или командировки. Бронирование временного размещения с возможностью оплаты через приложение.

**Место в сценарии:** Доступен через навигацию из Home или из раздела благотворительности. Пользователь ищет передержку, просматривает варианты и бронирует размещение.

### 4.2. Элементы Интерфейса и Функциональность

**Компонент: Search Filters**
- Поля поиска:
  - **Город:** Выбор города
  - **Даты:** Календарь (заезд/выезд)
  - **Тип питомца:** Собака/Кошка/Другое
  - **Количество питомцев:** Число
- Кнопка "Найти": Применение фильтров

**Компонент: Boarding List**
- Список передержек, соответствующих фильтрам
- Карточки передержки:
  - Фото
  - Название
  - Адрес
  - Рейтинг
  - Цена за день

#### 4.2.2. Интерактивность

**Поиск передержек:**
- Заполнение фильтров
- Тап на "Найти"
- Обновление списка результатов

**Тап на карточку:**
- Переход на детальную информацию
- Возможность бронирования

### 4.3. Техническая Реализация

#### 4.3.1. Сервисы и API

**API Endpoint: GET /charity/boarding/search**
- Метод: `GET`
- Путь: `/charity/boarding/search`
- Query параметры:
  - `city`: Город
  - `checkIn`: Дата заезда
  - `checkOut`: Дата выезда
  - `petType`: Тип питомца
  - `petCount`: Количество

**Use Case: SearchBoardingUseCase**
- Входные данные: `BoardingSearchRequest(filters)`
- Выходные данные: `NetworkResult<[Boarding]>`

## 5. Donation (Пожертвование)

### 5.1. Цель и Контекст

**Бизнес-задача:** Безопасное и удобное пожертвование средств приютам через встроенную систему платежей. Прозрачность транзакций и возможность регулярных пожертвований.

**Место в сценарии:** Открывается из детальной информации о приюте или из списка приютов. Пользователь выбирает сумму и способ оплаты, подтверждает пожертвование.

### 5.2. Элементы Интерфейса и Функциональность

#### 5.2.1. Структура Экрана

**Компонент: Shelter Info**
- Название приюта
- Логотип
- Краткое описание

**Компонент: Amount Selection**
- Быстрые суммы: 100₽, 500₽, 1000₽, 2000₽, 5000₽
- Поле ввода: "Другая сумма"
- Минимальная сумма: Указана (например, 100₽)

**Компонент: Donation Type**
- Разовая пожертвование (по умолчанию)
- Регулярное пожертвование (ежемесячно)
- Выбор периода для регулярного

**Компонент: Payment Method**
- Выбор метода оплаты (как в Payment Screen)
- Интеграция с системой платежей

**Компонент: Submit Button**
- Кнопка "Пожертвовать [сумма]" (Primary button)
- Действие: `viewModel.processDonation()`

#### 5.2.2. Интерактивность

**Выбор суммы:**
- Тап на быструю сумму → установка значения
- Ввод произвольной суммы
- Валидация: Минимальная сумма

**Выбор типа:**
- Переключатель между разовой и регулярной
- Для регулярной: выбор периода

**Обработка платежа:**
- Интеграция с Payment Screen
- Обработка через систему платежей
